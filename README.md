# Rol de Misiones para los Caballeros del Zodiaco (Java 21 + IntelliJ IDEA Swing UI Designer)

## Requisitos
- **JDK 21** (Amazon Corretto 21 / OpenJDK 21 / Oracle JDK 21)
- **IntelliJ IDEA** (Community o Ultimate)

## Cómo abrir y ejecutar en IntelliJ IDEA
1. Descomprimir la carpeta `CaballerosZodiaco_IntelliJ`.
2. En IntelliJ IDEA: **File -> Open...** y seleccionar la carpeta `CaballerosZodiaco_IntelliJ`.
3. Verificar en **File -> Project Structure -> Project** que el SDK sea **Java 21**.
4. Abrir `src/ec/udla/zodiaco/vista/VentanaSantuario.form` para visualizar y editar la interfaz gráfica arrastrando componentes en **Swing UI Designer**.
5. Ejecutar la clase principal `ec.udla.zodiaco.Main` (**Run 'Main.main()'**).
6. Para ejecutar las pruebas unitarias o el benchmark de complejidad, ejecutar `PruebasUnitarias` o `BenchmarkEstructuras` en el paquete `ec.udla.zodiaco.pruebas`.
